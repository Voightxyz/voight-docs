## The honest framing

Two principles run through the document:

1. **Observability is detection and monitoring, not prevention.** For most risks, Voight helps you *see* and *investigate* a problem — it does not sit inline to *block* it. Where this matters, the document says so.
2. **No claimed coverage we don't have.** Two of the ten risks fall outside what an observability platform addresses, because Voight neither trains models nor manages vector stores. The document states this plainly rather than stretch a weak angle.

## Voight's own posture

Today, Voight does not operate a large language model within its own product — it is the observability platform that *receives* LLM telemetry. The document records Voight's platform security baseline (shared with the [GDPR documentation](/trust/gdpr)) and a forward commitment: when Voight's roadmap LLM features (Smart Trace, Prompt Scorer, Debug Agent) reach production, this document will be re-versioned to assess each against the relevant risks, holding our own features to the same standard we help our customers meet.
