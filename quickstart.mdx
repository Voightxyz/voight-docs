Voight works with any agent stack — coding assistants, autonomous frameworks, and custom runtimes. Pick the install path that fits yours; the dashboard, the privacy model, and the API are the same on every path.

## Step 1 — Generate an API key

Open [voight.xyz/dashboard/settings](https://voight.xyz/dashboard/settings) and click **+ Generate key**. Copy the `vk_...` secret. **You'll only see it once** — save it to a password manager.

## Step 2 — Pick your install path

### A · Coding agent (Claude Code, Cursor, Codex…)

A wizard writes the right hooks and env into your IDE's config. No code changes.

```bash
npx -y @voightxyz/sdk setup
```

It asks for a [privacy level](/privacy/overview), accepts your API key, and wires up the lifecycle hooks. Idempotent — safe to re-run.

Verified today for **Claude Code**. Cursor and Codex targets are scaffolded — see [SDK targets](/sdk/library-mode#verified-vs-scaffolded-targets).

### B · Autonomous agent (ElizaOS, Solana Agent Kit, custom)

Install the SDK as a library and call `voight.log()` from your agent code.

```bash
npm install @voightxyz/sdk
```

```ts
import { voight } from '@voightxyz/sdk'

voight.init({ key: process.env.VOIGHT_KEY })

await voight.log({
  kind: 'decision',
  agentId: 'my-trading-bot',
  input: 'should I rebalance?',
  metadata: { confidence: 0.82 },
})
```

Full reference in [Library mode](/sdk/library-mode).

### C · Any language over HTTP

If your runtime isn't Node — Python, Go, Rust, anything that speaks JSON — POST events directly. No SDK required.

```bash
curl https://voight-production.up.railway.app/v1/events \
  -H "authorization: Bearer $VOIGHT_KEY" \
  -H "content-type: application/json" \
  -d '{
    "kind": "decision",
    "agentId": "my-agent",
    "input": "hello world"
  }'
```

Full schema in the [HTTP API reference](/api-reference/events).

## Step 3 — Verify in the dashboard

Open [voight.xyz/dashboard](https://voight.xyz/dashboard). Within seconds you should see:

- A new agent in the **Agents** list (auto-named from your install path, renameable)
- Events streaming in the **Overview** and **Audit log**
- Token counts, cost USD, and model tags on each event
- A per-event privacy chip (`MIN` / `STD` / `FULL`) confirming which level captured it

## Non-TTY install for path A

If `stdin` isn't an interactive TTY (running the wizard from inside a chat agent, CI, or any non-interactive shell), the setup runs in **3-step progressive mode**:

```bash
# Step 1 — see the menu
npx -y @voightxyz/sdk setup

# Step 2 — pick a privacy level
npx -y @voightxyz/sdk setup --privacy=2

# Step 3 — paste your key
npx -y @voightxyz/sdk setup --privacy=2 --key=vk_YOUR_KEY
```

Each step prints instructions and exits cleanly. Chains naturally for both humans and AI agents reading the output.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Events aren't showing up">
    1. Confirm the SDK version: `npx -y @voightxyz/sdk@latest --version` (should be 0.4.2 or higher).
    2. For path A — check your IDE's settings file (`~/.claude/settings.json` for Claude Code): `env.VOIGHT_KEY` should be set and `hooks` should contain entries calling `npx -y @voightxyz/sdk hook`. **Restart your IDE** afterwards — hooks are read on startup.
    3. For path B / C — confirm your code is actually calling `voight.log()` or POSTing, and that `VOIGHT_KEY` is set in the runtime environment.
    4. Check the dashboard's **Audit log** for the most recent events — they should appear within ~2 seconds of being sent.
  </Accordion>
  <Accordion title="npx serves an old SDK version">
    Force the latest with an explicit version:

    ```bash
    npx -y @voightxyz/sdk@0.4.2 setup
    ```

    Or clear the npx cache:

    ```bash
    rm -rf ~/.npm/_npx
    ```
  </Accordion>
  <Accordion title="The SDK isn't capturing my prompts">
    You're probably on Minimal mode, which strips content fields by design. Re-run setup with Standard or Full:

    ```bash
    npx -y @voightxyz/sdk setup --privacy=standard
    ```

    Or for path B / C, pass the level on `voight.init({ privacy: 'standard' })`.
  </Accordion>
  <Accordion title="My IDE shows a warning about the package">
    Some coding agents flag unfamiliar packages installed with `-y` for safety. The two-line copy block in your [dashboard onboarding](https://voight.xyz/dashboard/settings) includes a framing line ("Set up Voight observability here:") that gives the agent the intent it needs to skip the warning.
  </Accordion>
</AccordionGroup>
