This quickstart wires the Voight SDK into Claude Code — the most common path. If you're integrating with Cursor, Codex, or building autonomous agents, see the [SDK guides](/sdk/claude-code) instead.

## Prerequisites

- Node.js 18 or newer
- A Voight account at [voight.xyz/dashboard](https://voight.xyz/dashboard) (sign in with Google, X, or a Solana wallet via Privy)

## Step 1 — Generate an API key

Open [voight.xyz/dashboard/settings](https://voight.xyz/dashboard/settings) and click **+ Generate key**. Copy the `vk_...` secret. **You'll only see it once** — save it to a password manager.

## Step 2 — Run the setup wizard

In your terminal (or in any Claude Code chat — the wizard works both ways):

```bash
npx -y @voightxyz/sdk setup
```

The wizard walks you through:

<Steps>
  <Step title="Pick a privacy level">
    Three options. Read the [privacy overview](/privacy/overview) for the full breakdown.

    - **1) Minimal** — metadata only (tool names, timing, tokens, USD). No prompts, responses, file paths, cwd, git context leave your machine.
    - **2) Standard** ★ — full content with local PII scrubbing. Credentials and personal info redacted on your machine before transmission.
    - **3) Full** — everything captured as-is.
  </Step>
  <Step title="Paste your API key">
    The wizard validates the `vk_` prefix and stores it in `~/.claude/settings.json` under `env.VOIGHT_KEY`.
  </Step>
  <Step title="Done">
    The wizard wires up 7 Claude Code hooks (PreToolUse, PostToolUse, UserPromptSubmit, Stop, etc.) idempotently. You'll see:

    ```
    🎉 You're all set!

      ✓ Standard mode enabled
      ✓ 7 hooks wired into Claude Code
      ✓ API key configured

      → See your agent live: https://voight.xyz/dashboard
    ```
  </Step>
</Steps>

## Step 3 — Trigger your first event

Open Claude Code (or start a new chat session). Ask it to do anything — run a Bash command, read a file, edit code. Within seconds, the event will appear at [voight.xyz/dashboard](https://voight.xyz/dashboard) in the live timeline.

## Step 4 — Verify in the dashboard

You should see:

- A new agent in the **Agents** list (`claude-code:<your-project>` or your cuid if you renamed)
- Events streaming in the **Overview** and **Audit log**
- Token counts, cost USD, and model tags on each event
- A per-event privacy chip (`MIN` / `STD` / `FULL`) confirming which level captured it

## Non-TTY install (Claude Code chat, CI, agents)

If `stdin` isn't a TTY (running inside Claude Code chat, CI, or any non-interactive shell), the wizard runs in **3-step progressive mode**:

```bash
# Step 1 — see the menu
npx -y @voightxyz/sdk setup

# Step 2 — pick a level
npx -y @voightxyz/sdk setup --privacy=2

# Step 3 — paste your key
npx -y @voightxyz/sdk setup --privacy=2 --key=vk_YOUR_KEY
```

Each step prints clear instructions and exits. The flow chains naturally for both humans and AI agents reading the output.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Events aren't showing up">
    1. Confirm the SDK version: `npx -y @voightxyz/sdk@latest --version` (should be 0.4.2 or higher).
    2. Check `~/.claude/settings.json` — `env.VOIGHT_KEY` should be set and `hooks` should have entries calling `npx -y @voightxyz/sdk hook`.
    3. **Restart Claude Code** (or open a fresh chat). The hook subprocess only reads settings on startup.
    4. In Claude Code, run any tool (e.g. `Bash $ ls`). The PostToolUse hook fires after every tool call.
    5. Check the dashboard's **Audit log** for the most recent events — they should appear within ~2 seconds.
  </Accordion>
  <Accordion title="npx serves an old SDK version">
    Force the latest with an explicit version:

    ```bash
    npx -y @voightxyz/sdk@0.4.2 setup
    ```

    Or clear the npx cache:

    ```bash
    rm -rf ~/.npm/_npx
    ```
  </Accordion>
  <Accordion title="The SDK isn't capturing my prompts">
    You're probably on Minimal mode. Re-run setup and pick Standard or Full:

    ```bash
    npx -y @voightxyz/sdk setup --privacy=standard
    ```
  </Accordion>
  <Accordion title="Claude Code shows a warning about the package">
    Claude Code flags unfamiliar packages with `-y` for safety. The two-line copy block in your [dashboard onboarding](https://voight.xyz/dashboard/settings) includes a framing line ("Set up Voight observability here:") that gives Claude Code the intent it needs to skip the warning.
  </Accordion>
</AccordionGroup>
