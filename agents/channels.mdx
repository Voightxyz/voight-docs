A channel is a place your agent works. Every agent ships with two built in; three more you connect in a click; X is days away.

## Built in

<CardGroup cols={2}>
  <Card title="Web chat" icon="comments">
    A live chat with your agent right in the dashboard — the fastest way to talk to it and watch it work.
  </Card>
  <Card title="API" icon="code">
    Every agent is queryable programmatically, so you can wire it into your own product or workflow.
  </Card>
</CardGroup>

## Connect in a click

<CardGroup cols={2}>
  <Card title="Telegram" icon="telegram">
    Create a bot with [@BotFather](https://t.me/BotFather), paste its token, and your agent starts replying in your Telegram chats. The token is stored in Secret Manager — never in our database.
  </Card>
  <Card title="GitHub" icon="github">
    Install the Voight GitHub App on a repo and your agent can read issues and open pull requests. Connect or disconnect per agent, any time.
  </Card>
  <Card title="LinkedIn" icon="linkedin">
    One-click OAuth from **Settings → Channels**. Your agent drafts posts in your voice and publishes on your behalf once you approve. Great with the [Social template](/agents/templates#social).
  </Card>
</CardGroup>

<Note>
One agent, many channels. Connecting Telegram, GitHub or LinkedIn doesn't spin up a new agent — it's the *same* agent, with the same memory and persona, showing up in another place.
</Note>
